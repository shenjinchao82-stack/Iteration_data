This modeling study selected four models for rainfall prediction: multiple linear regression, LightGBM, XGBoost, and random forest. Multiple linear regression serves as the foundational model, providing a simple and interpretable baseline result. LightGBM and XGBoost are gradient boosting tree models, suitable for handling tabular data with strong nonlinear relationships, capable of learning complex relationships between months, geographic locations, and historical rainfall. Random forest is an ensemble learning model that improves prediction stability and generalization ability by constructing multiple decision trees, commonly used for meteorological, geographical, and environmental data prediction tasks. Therefore, these models encompass both simple linear models and commonly used nonlinear ensemble models, allowing for a comprehensive comparison of the performance of different modeling methods in rainfall prediction.

The selection of the optimal model was primarily based on cross-validation results and test set performance. K-fold cross-validation was used in the code, with Mean Absolute Error (MAE) as the main evaluation metric. MAE represents the average absolute difference between predicted and actual values, expressed in millimeters; a smaller value indicates lower prediction error. MAE, RMSE, and R² on the test set were also considered. RMSE is more sensitive to larger errors, while R² measures the model's explanatory power for rainfall variations; a value closer to 1 indicates a better fit. The model comparison results show that Random Forest had the lowest cross-validation MAE (10.4377) and the lowest test set MAE (9.5850), while achieving a test set R² of 0.9492, indicating the smallest prediction error and the strongest explanatory power. Therefore, Random Forest was ultimately selected as the optimal model for rainfall prediction from May to October 2026.
